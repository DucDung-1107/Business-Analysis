## Scope and lineage

The input is read from the path in `configs/preprocess_v1.json`. The pipeline stores a SHA-256 hash of the raw file, config hash, output hashes, quality audit and deterministic data version in `manifest.json`; it also writes the same manifest to `reports/data_quality/` for review and version control. Processed CSV files are excluded from Git because they derive from the raw file. Commit the config, code, dictionary and reviewed manifest—not the raw source or customer-level extracts.

`churn` is a static source label. The current extract has no observation timestamp, prediction point or label window, so preprocessing v1 does not support a next-quarter prediction claim or temporal validation.
